# Navigation

**Component:** `Navigation SDUI`
**Library:** DS Components SDUI Library (`eTFJFet7kxp4d8yFtPZfue`)

---

## Overview

Navigation is a structural component covering the full range of navigation surfaces across platforms and viewports. The raw spec file contains variant definitions only — no standalone guideline, behavior, or accessibility prose. Usage guidance lives within the individual sub-surface specs (e.g., Global Search, Left Rail).

---

## Variants

### Search types
| Variant | Description |
|---|---|
| **Home Search** | Global search surface on the home/feed page. |
| **Leaf Search** | Search surface on a leaf (interior) page. |
| **Leaf Search (Button)** | Leaf search in button trigger form. |
| **Leaf Page** | Navigation header for a leaf/interior page. |
| **Full-page modal** | Navigation as a full-page modal overlay. |
| **Full-page modal (Button)** | Full-page modal triggered by a button. |
