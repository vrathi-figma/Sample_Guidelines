# Divider

**Component:** `Divider SDUI`
**Library:** DS Components SDUI Library (`eTFJFet7kxp4d8yFtPZfue`)

---

## When to use

- Use to visually separate content by topic, focus, or interaction.
- Use to separate groups of content, not individual items.
- Do not use as a substitute for whitespace — dividers support layout structure, not replace spacing.
- Do not use to surround items. Use containers or surfaces with different background colors instead.

**Use sparingly — separate by group, not by item:**

**Do:** Use dividers between content groups (e.g. between "Recent", "Groups", "Events", "Followed Hashtags").
**Don't:** Use a divider between every individual item in a list.

**Do not use a divider to surround items:**

**Do:** Use cards or surfaces with different background colors to contain grouped items.
**Don't:** Place dividers around the edges of item groups to create a box effect.

---

## Types

| Direction | Use |
|---|---|
| Horizontal | Separates content vertically (stacked sections). |
| Vertical | Separates content horizontally (side-by-side elements). |

---

## Placement

**Full-bleed:** Spans the full width of the parent container. Use to separate major sections that may not be directly related but contribute to the same layout.

**Inset:** Aligned to one side (not full-width). Use in lists where anchoring elements (images, icons) are present — keeps separation without adding clutter.

**Middle:** Centered, doesn't span full width. Use to separate related content within a section (e.g. between social proof counts and action buttons in a feed post).

---

## Adaptability

- Horizontal: no fixed width, fixed height — grows/shrinks with parent container horizontally.
- Vertical: no fixed height, fixed width — grows/shrinks with parent container vertically.

---

## Accessibility

**Color & Contrast:**
- All default colors meet minimum contrast requirements for light and dark modes.
- Divider is decorative — no role or accessible name required.
